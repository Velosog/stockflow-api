## [0.1.0] - 2026-10-16

First public release.

### Added

- Token authentication (Laravel Sanctum) with expiring, prefixed tokens, logout and timing-safe login.
- Roles (`admin`, `manager`, `operator`) with a single permission matrix and a policy check on every endpoint.
- Products (soft deletes, trigram search) and warehouses.
- Append-only stock ledger enforced by a PostgreSQL trigger, plus denormalised stock levels with a generated `available` column and CHECK constraints.
- Orders with stock reservation under row locks (`SELECT ... FOR UPDATE`, deadlock-free lock order), confirmation, cancellation and a 409 for invalid status transitions.
- `Idempotency-Key` support on `POST /api/v1/orders`.
- Queued low-stock alerts sent to managers as database notifications, and endpoints to read them.
- Rate limits for login, API traffic and writes.
- RFC 9457 problem details for every error, request ids and security headers.
- OpenAPI 3.1 documentation generated by Scramble and exported to `docs/openapi.json`.
- Docker Compose stack (FrankenPHP app, queue worker, scheduler, PostgreSQL 18) and a demo seeder.
- Pest test suite (unit, feature and multi-process concurrency tests), PHPStan level 8, Pint.
- CI: composer validate/audit, Pint, PHPStan, tests on PostgreSQL, Docker smoke test and gitleaks.
- Security baseline: gitleaks pre-commit hook, Dependabot and SECURITY.md.
